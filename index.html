Base de données Supabase

Synchronise ton frigo dans le cloud entre tous tes appareils.

Activer péremption et menu de la semaine.
1. Ouvre Supabase → SQL Editor → New query
2. Colle le script ci-dessous → Run
Il n'efface rien et peut être relancé autant de fois que nécessaire.

-- 1. Dates de péremption : ajoute une colonne, ne touche pas aux données
alter table inventaire
  add column if not exists date_peremption date;

-- 2. Menu de la semaine : nouvelle table, indépendante d'inventaire
create table if not exists menu_semaine (
  id bigint generated by default as identity primary key,
  semaine text not null,
  recette_id bigint not null,
  titre text not null,
  image text,
  portions int default 2,
  personnes int default 2,
  nutrition jsonb,
  ingredients jsonb,
  etapes jsonb,
  lien text,
  cree_le timestamptz default now()
);

-- Si la table existe deja sans ces colonnes :
alter table menu_semaine add column if not exists etapes jsonb;
alter table menu_semaine add column if not exists lien text;
alter table menu_semaine add column if not exists ajoute_par text;

create index if not exists menu_semaine_semaine_idx
  on menu_semaine (semaine);

-- 3. Mêmes droits d'accès que ta table inventaire (clé anon)
alter table menu_semaine enable row level security;
drop policy if exists "acces menu" on menu_semaine;
create policy "acces menu" on menu_semaine
  for all using (true) with check (true);

Regroupe les lignes de même nom, quelle que soit leur catégorie, dès que les unités se convertissent (g/kg, ml/L). Si les unités diffèrent vraiment, l'outil te dit lesquelles corriger.

Traduction des recettes

Les recettes viennent de Spoonacular, en anglais. L'app traduit d'abord avec son dictionnaire interne, puis via MyMemory (gratuit, sans compte) pour le reste. Tout est mis en cache : une recette déjà traduite ne recoûte rien.

Traduire en français

Clé API Spoonacular

Nécessaire pour la recherche et l'analyse des recettes.

Le plan gratuit donne 50 points par jour (pas 50 requêtes). Une recherche coûte 1 + 0,035 point par recette demandée (soit 2,75 points pour 50 recettes), une fiche nutrition 1 point. Les résultats sont mis en cache 24 h : relancer la même recherche ne coûte rien.

Sauvegarde du stock

Télécharge une copie de ton stock actuel (fichier CSV, ouvrable dans un tableur). Un filet de sécurité en plus de la synchronisation Supabase.
